# 에셋 이동·이름 변경

에셋·폴더를 이동하거나 이름을 바꿀 때, 또는 `[SerializeField]` 필드 이름을 바꿀 때 읽는다. 이동·이름 변경 자체는 `core.md`의 `Unity 에셋 변경 원칙`에 따라 mcp-for-unity로 한다.

## 검증

- 시작 전에 열린 Scene·Prefab에 저장되지 않은 변경이 없는지 확인한다. 저장되지 않은 변경이 있으면 사용자에게 알린다.
- 완료 후 git에서 이름 변경(rename)으로 잡히는지 확인해 GUID 유지를 검증한다. 새 파일과 삭제로 잡히면 참조가 끊긴 것이다.
- Scene의 컴포넌트 참조와 Build Settings의 씬 경로가 유지되는지 확인한다. Build Settings처럼 Editor 메모리에서만 갱신된 설정은 프로젝트를 저장해 파일에 반영한다.
- `[SerializeField]` 필드 이름을 바꾸면 Scene·Prefab의 참조가 끊긴다. 변경 후 mcp-for-unity로 다시 연결하고 저장한다.

## 도구 주의사항

- mcp-for-unity의 에셋 이동은 스크립트 재컴파일 등으로 실패 응답을 반환해도 실제로는 이동되었을 수 있다. 재시도하기 전에 파일 시스템에서 결과를 확인한다.
